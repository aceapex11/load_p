# GridSense (Streamlit)
Files (all in one folder): `app.py`, `requirements.txt`, `SecureElite_DeviceID19_KW_gt_1.xlsx`, `README.md`.
Run: `pip install -r requirements.txt` then `streamlit run app.py`.
Deploy: push these files to the root of a GitHub repo -> share.streamlit.io -> main file `app.py`.
